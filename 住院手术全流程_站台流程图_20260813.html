从头到尾：7 个站台的责任流转

医生发起 护士承接 手术室资源 麻醉专业线 患者流转 术中证据
开始
住院患者已入院，有诊断与主管医生信息，具备住院手术上下文
01

手术申请住院医生站 · 医生发起

  • 选择已入院患者，确认姓名、住院号、科室、诊断、主管医生
  • 录入拟手术名称、诊断、主刀、拟手术时间、手术等级、切口等级
  • 系统校验主刀权限、手术等级及术前文书（术前讨论/知情同意）
  • 申请单保存成功，生成「待签收」状态
边界：申请≠执行发起只是医疗意图，须经签收、同步、排台、访视、交接后才进入执行链路。
02

病区签收病区护士站 · 病区承接

  • 病区护士签收手术相关医嘱 / 申请
  • 申请同步到手术管理系统（跨系统同步验证）
  • 状态流转：医生端 → 手术管理系统「待排台」
验证：手术管理系统能按患者/住院号/申请时间查到本次申请。
边界：签收≠入室签收是从医生诊疗动作转向病区执行管理的关键节点。
03

手术排台手术管理系统 · 手术室接手

  • 查询待安排手术，定位本次手术申请
  • 手术室护士长安排手术日期、手术间、台次
  • 指派巡回护士、器械护士
  • 手术从「申请」进入「计划执行」，排班表/通知单可见
本质：资源调度——把患者、手术间、台次、护士、麻醉人员、时间绑定。
04

麻醉安排麻醉科 · 专业线

  • 安排主麻、副麻或麻醉护士
  • 完成术前访视记录与麻醉评估
  • 完成麻醉知情同意
  • 确定麻醉风险、麻醉方式与术中监测重点
验证：可查看麻醉人员、访视记录或麻醉知情状态。
边界：麻醉是围手术期独立流程，不是附属字段。
05

转运入室病区 → 手术室 · 患者流转

  • 病区护士与手术室护士转运交接
  • 腕带 / 转运码 / 纸质交接单核对患者
  • 核对身份、手术名称、部位、禁食禁水、术前准备
  • 患者状态更新为「待入室 / 已入室」
兜底：PDA 是电子化交接方式，无设备时纸质/手工确认，业务重点仍是身份+术式+部位+双方确认。
06

术中记录手术室 · 证据留痕

  • 三方核查：麻醉前、手术前、离室前（医生+麻醉+手术室护士）
  • 术中护理记录（巡回、器械护士）与器械/敷料/针线清点
  • 麻醉记录单：时间轴、用药、输液输血、体征、事件、监护
  • 药品、耗材使用留痕，构成术中证据链
边界：医嘱来源术中检查/检验/病理/输血医嘱由同科室医生回住院医生站开立，医技系统执行，手麻系统只记录场景与证据。
07

术后闭环复苏/病区/收费/归档 · 结果回收

  • 记录手术结束、麻醉结束、出室时间，确认流向（复苏室/ICU/回病区）
  • PACU 复苏监测体征、苏醒、用药，达标后出复苏室回病区或转 ICU
  • 费用确认：手术费、麻醉费、耗材费、药品费进入患者账
  • 文书签名归档：麻醉、护理、手术文书 → 已完成 / 已归档
双闭环：①患者去向与复苏闭环；②费用确认与文书归档闭环。只完成手术动作 ≠ 流程完成。
结束
患者已安全出室并完成复苏，费用可追溯、文书已归档，住院手术闭环收口

四条必须讲清的系统边界

边界 1

申请 ≠ 执行

医生开申请只是发起医疗意图，只有经过签收、同步、排台、麻醉访视和转运交接，手术才真正进入执行链路。

边界 2

签收 ≠ 入室

病区护士签收是把医生诊疗动作转为病区执行管理，后续还要排台、访视、转运入室后才算真正开始执行。

边界 3

术中医嘱仍在住院医生站

术中检查、检验、病理、输血医嘱回住院医生站开立，LIS/PACS/病理/输血系统承接执行，手麻系统只记录场景与证据。

边界 4

入室后不随意作废

一旦进入入室/术中，涉及三方核查、清点与计费证据，不允许随意作废，异常按既有流程处理。

流程汇总

  1. 起点：住院医生站选择已入院患者，开立手术申请（术式、主刀、等级、时间）。
  2. 承接：病区护士签收，申请同步到手术管理系统；手术室护士长排台安排手术间、台次、护士。
  3. 专业线：麻醉科排班并完成术前访视、麻醉评估与知情同意。
  4. 流转：病区与手术室转运交接，入室后三方核查，术中完成护理记录、器械清点、麻醉记录。
  5. 收口：术后出室、复苏或转 ICU，费用确认进入患者账，麻醉/护理/手术文书签名归档，闭环结束。
